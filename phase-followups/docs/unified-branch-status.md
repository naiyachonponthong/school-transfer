## ข้อจำกัดที่รู้

- Web Push ต้องเปิดเว็บผ่าน https (หรือ localhost) และยังไม่ได้ทดสอบกับเบราว์เซอร์จริงทุกยี่ห้อ ทดสอบแล้วเฉพาะการลงชื่อ VAPID และขั้นตอนฝั่งเซิร์ฟเวอร์
- LINE Login ต้องอยู่ใต้ Provider เดียวกับ LINE OA รหัสผู้ใช้จึงจะตรงกับที่ใช้ส่งแจ้งเตือน ยังไม่ได้ทดสอบกับช่อง LINE จริง
- ผลรายปีของประถมคิดตอนแสดง ปพ.1 เท่านั้น สมุดพก (ปพ.6) ยังแสดงรายภาค
- ยืนยันตัวตน 2 ขั้นทดสอบกับค่าทดสอบของ RFC 6238 และขั้นตอนฝั่งเซิร์ฟเวอร์แล้ว ยังไม่ได้ทดลองสแกน QR ด้วยแอปบนมือถือจริง
- การล็อกแถวตอนออกใบจ่ายเงินร้านค้า (`lockForUpdate`) ไม่มีผลบน SQLite จึงยังไม่ได้ทดสอบการกดจ่ายพร้อมกันสองเครื่องบน MySQL
- หมวดสินค้าที่ไม่ให้ซื้อกันได้เฉพาะสินค้าที่ร้านเลือกจากรายการ บรรทัดที่คนขายกดจำนวนเงินเองไม่มีหมวด
- `CashClosing` และ `StudentDiscount.value` ยัง cast เป็น `float` (ยอดสรุป ณ ตอนปิด และค่าที่เป็นได้ทั้งร้อยละและบาท)
- รายการถอนคืนที่บันทึกก่อนมีช่องวิธีคืนเงิน ถือเป็นเงินสดในหน้าปิดยอดรายวัน
