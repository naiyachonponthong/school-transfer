## ที่ไม่ได้ย้าย เพราะใช้ของฐานแทน

- การเก็บผลการเรียนตอนล็อก (ฐานคำนวณสดและเก็บเฉพาะ ร/มส/ผลแก้ตัว)
- หน้าประเมินคุณลักษณะ ปพ.5 ปพ.7 ของงานเดิม
- ตาราง `activity_logs` และ trait บันทึกอัตโนมัติ (ใช้ `Audit::log` ของฐาน)
- แจ้งซ่อมและจองห้องของงานเดิม
- สำรองไฟล์และ CI ของงานเดิม

## ที่ตัดออก

- เกรดรายปีของประถม (ฐานมีการแสดงผลรายปีใน ปพ.1:ป ด้วยน้ำหนักเวลาเรียนอยู่แล้ว การรวมคะแนนสองภาคแล้วตัดเกรดครั้งเดียวขัดกับวิธีนั้น)
- ประเภทช่องคะแนน (ระหว่างภาค/กลางภาค/ปลายภาค)

## ข้อจำกัดที่รู้

- กระดิ่งแจ้งเตือนของตำแหน่งการเงิน/บุคคล/รับสมัคร ยังแสดงรวมกันทั้งสามเรื่อง
- ปพ.1 ไม่ได้ซ่อนภาคเรียนที่ยังไม่ถึงวันประกาศผล (ซ่อนเฉพาะ ปพ.6 และแท็บผลการเรียน)
- ตารางเรียนของนักเรียนแสดงตามห้อง ไม่รวมคาบของวิชาเลือกที่เรียนกับห้องอื่น
- ผังค่าธรรมเนียม ดูแลช่วยเหลือ สารบรรณ ฯลฯ ยังไม่มีหัวข้อในคู่มือในระบบ (`/manual`)
- Web Push และ LINE Login ยังไม่ได้ทำ
